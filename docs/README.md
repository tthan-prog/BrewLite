# Bản đồ tài liệu – BrewLite

Thư mục `docs/` được chia theo bài tập lớn để biết ngay đang đọc tài liệu của bài nào.

| Thư mục / file | Thuộc | Nội dung |
|---|---|---|
| `as1/` | Assignment 1 (giữa kì) | Báo cáo, Scrum (backlog, burndown, biên bản, nghiệm thu), phân công, tiến độ, tin nhắn nộp bài |
| `as2/` | Assignment 2 (cuối kì) | Báo cáo, biên bản Scrum, bằng chứng CI/CD và production, release notes, phân công, tin nhắn nộp bài |
| `chung/` | Cả hai bài | Thỏa thuận nhóm, bảng đóng góp, hướng dẫn build báo cáo, mẫu biên bản, ERD |
| `requirements/`, `diagrams/`, `architecture/`, `traceability-matrix.md`, `deployment.md` | Assignment 2 | Tạo phẩm Task 1–3 và triển khai. Đề Assignment 2 yêu cầu đúng các đường dẫn này nên **không** nằm trong `as2/` |
