\section{Phần giới thiệu}
\subsection{Bối cảnh và mục tiêu}
BrewLite là ứng dụng web mobile-first giúp khách đặt đồ uống và thanh toán không dùng tiền mặt: xem menu, chọn size/topping, thêm vào giỏ, đăng nhập, đặt đơn, thanh toán mô phỏng (Ví/Thẻ) và xem lịch sử đơn. Bài tập lớn gồm 10 task theo Agile Scrum (mỗi task 1 điểm), kèm bốn nghiệp vụ backend nâng cao ở Task 10. Hạn nộp: 02/11/2026.

\subsection{Task 10 -- nghiệp vụ backend}
Bốn nghiệp vụ: (1) máy trạng thái đơn (PENDING, PAID, PREPARING, READY, COMPLETED, thêm PAYMENT\_FAILED và CANCELLED), mọi chuyển trạng thái đi qua một hàm kiểm tra duy nhất; (2) thanh toán idempotent bằng \texttt{Idempotency-Key}, ràng buộc duy nhất theo \texttt{(userId, key)}; (3) kiểm soát tồn kho đồng thời bằng cập nhật có điều kiện trong transaction (không bán quá số lượng; nguyên liệu chỉ trừ khi thanh toán thành công, hủy đơn hoàn lại phần đã trừ); (4) mã khuyến mãi (\texttt{WELCOME10} giảm 10\%) và điểm thưởng (1 điểm cho mỗi 10.000 đồng, cộng khi đơn PAID).

\begin{mdframed}[hidealllines=true,backgroundcolor=magenta!10]
\begin{lstlisting}[language=Java]
export const ORDER_TRANSITIONS = {
  PENDING:        ['PAID', 'PAYMENT_FAILED', 'CANCELLED'],
  PAYMENT_FAILED: ['PENDING', 'CANCELLED'],
  PAID:           ['PREPARING', 'CANCELLED'],
  PREPARING:      ['READY'],
  READY:          ['COMPLETED'],
  COMPLETED: [], CANCELLED: [],
};
export function assertTransition(from, to): void {
  if (!ORDER_TRANSITIONS[from].includes(to))
    throw new BadRequestException(/* invalid transition */);
}
\end{lstlisting}
\end{mdframed}

\subsection{Ba test bắt buộc của Task 10}
\begin{itemize}
    \item (a) Chặn chuyển trạng thái sai: đơn PAID không nhảy thẳng sang COMPLETED, trả HTTP 400 -- \textbf{đạt}.
    \item (b) Gửi hai lần cùng \texttt{Idempotency-Key} chỉ tạo một đơn và không thanh toán lần hai -- \textbf{đạt}.
    \item (c) 20 yêu cầu đặt đồng thời khi kho còn 5: đúng 5 đơn thành công, không âm kho -- \textbf{đạt}.
\end{itemize}
