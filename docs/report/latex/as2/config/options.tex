% --- 1. Bộ nội dung (profile) -----------------------------------------
% general : báo cáo tổng quát (mở đầu - cơ sở - thiết kế - triển khai - kết quả - kết luận)
% se      : môn Công nghệ phần mềm (Scrum, yêu cầu, UML, kiến trúc, CI/CD, kiểm thử, truy vết)
% paper   : bài tập phân tích bài báo khoa học (PPNCKH)
