# Báo cáo Assignment 2 (LaTeX)

Dựng theo mẫu `Assigment_template_SGU` (bìa có logo, mục lục, header/footer, các mục đánh số, khung code, tài liệu tham khảo).

- File chính: `main.tex` (một file, không có thư mục con để biên dịch).
- Trình biên dịch: **pdfLaTeX** (gói `vntex`). Máy cục bộ: `latexmk main.tex` hoặc `pdflatex main.tex` (chạy 2 lần để cập nhật mục lục). Overleaf: Compiler = pdfLaTeX.
- Cần 2 file logo cùng thư mục: `logoITSGU.png`, `logoITSGUsmall.png`.
- Chưa điền: MSSV của 4 thành viên (ô đỏ `\fillme{MSSV}` trên trang bìa).
