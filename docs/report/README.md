# Báo cáo LaTeX

Giảng viên yêu cầu nộp báo cáo bằng LaTeX theo mẫu `Assigment_template_SGU`. Mỗi báo cáo là một thư mục:

| Thư mục | Nội dung |
|---|---|
| `latex/as1` | Assignment 1 (Scrum, 10 task; nội dung gọn khoảng 3 trang) |
| `latex/as2` | Assignment 2 (yêu cầu, mô hình hóa, kiến trúc, CI/CD, triển khai, truy vết) |

Biên dịch: pdfLaTeX, file chính `main.tex` (xem README trong từng thư mục). Ảnh dùng trong báo cáo nằm ở `latex/as2/uml/` và `latex/as2/figures/`; sơ đồ nguồn PlantUML ở `docs/diagrams/`.

Chưa điền: MSSV (ô `\fillme{MSSV}` trên trang bìa).
